# CV

Source repository for my CV, typeset with [Typst](https://typst.app/).

Sensitive contact details are intentionally **not stored in this repository**. They are read from a local `personal.yaml` file that is ignored by Git. An optional profile photo is also local-only.

## Repository contents

- `cv.typ` - CV layout and public content.
- `personal.example.yaml` - example structure for local private contact data.
- `personal.yaml` - local private data; never commit this file.
- `photo.jpg` / `photo.png` / `photo.webp` - optional local profile photo; never commit it.
- `build.ps1` - optimizes the local profile photo when enabled and builds the standard PDF into `output/`.
- `build-europass.ps1` - opens the official Europass editor in Microsoft Edge and assists with filling it from the current CV.
- `scripts/read-cv-data.mjs` - reads the public CV data from `cv.typ` and private contact data from `personal.yaml`.
- `scripts/europass-fill.mjs` - Playwright-based browser automation for the official Europass editor.
- `.github/workflows/privacy-check.yml` - validates the Typst source and blocks accidental commits of private/generated browser state.

## Build the standard CV on Windows

1. Install the Typst CLI and make sure `typst` is available in `PATH`.
2. Create your local private data file:

   ```powershell
   Copy-Item personal.example.yaml personal.yaml
   ```

3. Edit `personal.yaml` and fill in your real contact details:

   ```yaml
   location: "City, Country"
   phone: "+00 000 0000000"
   email: "name@example.com"
   show_photo: false
   photo_path: "photo.jpg"
   ```

4. Optional: put your profile photo next to `cv.typ` and set `show_photo: true`.
5. Build the CV:

   ```powershell
   .\build.ps1
   ```

The generated file is written to:

```text
output/Vitalii_Hanych_CV.pdf
```

## Fill the official Europass CV

The Europass workflow deliberately does **not** generate an imitation Europass PDF or legacy Europass XML. It opens the official Europass editor so that the final PDF is generated by Europass itself.

Requirements:

- Node.js with npm.
- Microsoft Edge.
- `personal.yaml` configured as described above.

Run:

```powershell
.\build-europass.ps1
```

For the Italian Europass UI:

```powershell
.\build-europass.ps1 -Language it
```

On the first run the script installs two local npm dependencies: `playwright-core` and `yaml`. It uses the installed Microsoft Edge browser, so it does not download a separate Chromium build.

The automation:

1. Reads public CV content directly from `cv.typ`.
2. Reads contact information and the optional photo path from local `personal.yaml`.
3. Opens the official Europass CV editor.
4. Lets you complete EU Login manually if required. The script does not read or store your password.
5. Tries to populate personal information, About me, work experience, education, languages, skills and projects using accessible field labels instead of generated CSS class names.
6. If Europass changes a navigation control, the script asks you to open the corresponding form and press Enter; it then fills the form so you do not have to retype the CV content.
7. Leaves the browser open for review, template selection and the final PDF download from Europass.

The browser session is stored locally in `.europass-browser-profile/`, so EU Login can persist between runs. If the site changes enough to stop the automation, diagnostic screenshots and HTML are written to `.europass-debug/`. Both directories are ignored by Git and may contain private data.

## Privacy rule

Never force-add `personal.yaml`, your local photo, generated PDFs, `.europass-browser-profile/`, or `.europass-debug/` to Git. Browser-profile/debug data can contain authentication/session or personal information.
